# Roma Finanzas PWA

Aplicación de gestión financiera diseñada específicamente para salones de belleza en Cuba, como parte del ecosistema RservasRoma.

## Características principales:
- **Dashboard:** Resumen diario de ingresos, gastos, ganancias estimadas y margen.
- **Servicios y Materiales:** Catálogos para el control de precios y costos unitarios.
- **Ficha de Costo:** Calculadora de rentabilidad por cada servicio, teniendo en cuenta tasas de cambio y costos de productos.
- **Gestión Multi-moneda:** Soporte para CUP, USD, MLC, EUR con tasas configurables.

## Reglas de mantenimiento:
- **Siempre que se actualice la aplicación o se agregue una nueva característica, se debe revisar y actualizar este archivo README.md.**
- Mantener siempre la estructura de componentes dividida para facilitar la lectura.
- Respetar el diseño UI: Limpio, femenino y profesional (blanco, negro y rosa #ec4899).
